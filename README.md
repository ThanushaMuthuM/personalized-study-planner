# 📚 Smart Study Planner

A Flask-based web application that helps students create personalized study schedules based on subject priorities and available study hours. The planner includes smart break scheduling, motivational tips, progress tracking, PDF export, and study time visualization.

## 🚀 Features

* 📅 Personalized study schedule generation
* ⏰ Priority-based study hour allocation
* ☕ Smart break suggestions
* 📄 Export study schedule as PDF
* 📊 Pie chart visualization of study hours
* ✅ Mark completed subjects as done
* 💡 Random motivational tips
* 🌐 Simple and responsive web interface

## 🛠️ Tech Stack

* **Frontend:** HTML, CSS, JavaScript
* **Backend:** Python, Flask
* **Libraries:**

  * ReportLab
  * Matplotlib
* **Session Management:** Flask Session

## ⚙️ Installation

1. Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/study-planner.git
cd study-planner
```

2. Create a virtual environment

```bash
python -m venv .venv
```

3. Activate the virtual environment

**Windows**

```bash
.venv\Scripts\activate
```

4. Install dependencies

```bash
pip install -r requirements.txt
```

5. Run the application

```bash
python app.py
```

6. Open your browser

```
http://127.0.0.1:5000
```
